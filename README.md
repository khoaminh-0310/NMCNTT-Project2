## Hướng dẫn cài đặt và chạy ứng dụng:
1. Khởi tạo và kích hoạt môi trường ảo:
   python -m venv venv
   venv\Scripts\activate
2. Cài đặt các thư viện phụ thuộc:
   pip install -r requirements.txt
3. Khởi chạy ứng dụng Web Gradio:
   python app.py
