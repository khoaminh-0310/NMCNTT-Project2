# 10 ảnh kiểm thử – ảnh chụp thật từ scikit-image sample data

Đã thay toàn bộ ảnh đồ họa trong bản ZIP cũ bằng ảnh chụp mẫu có sẵn trong thư viện scikit-image. Ảnh 06–10 là biến thể xử lý từ ảnh chụp thật để tạo tình huống khó; **không** phải năm ảnh chụp độc lập.

| File | Vật thể / điều kiện |
|---|---|
| 01_coffee_cup.png | Cốc cà phê trên bàn |
| 02_camera.png | Máy ảnh |
| 03_clock.png | Đồng hồ |
| 04_coins.png | Nhiều đồng xu |
| 05_cat.png | Mèo |
| 06_coffee_background.png | Cốc và bối cảnh trên bàn |
| 07_camera_dark.png | Ảnh máy ảnh giảm sáng |
| 08_clock_small.png | Đồng hồ thu nhỏ trong khung trắng |
| 09_cat_blur.png | Ảnh mèo bị làm mờ |
| 10_coffee_occluded.png | Cốc bị che khuất một phần |

**Nguồn:** `skimage.data.coffee`, `camera`, `clock`, `coins`, `chelsea`; ảnh mẫu được phân phối cùng scikit-image. Chi tiết nguồn gốc và điều khoản từng ảnh: https://scikit-image.org/docs/stable/api/skimage.data.html . Các ảnh 07–10 đã chỉnh sửa cho mục đích kiểm thử.

**Quan trọng:** Bộ này dùng được để thử upload, kiểm thử với ảnh chụp và xử lý ảnh kém chất lượng. Bộ **chưa đạt đầy đủ yêu cầu Mục 8.4 của PDF về 5 ảnh vật thể cụ thể** (ghế, bàn, bóng, xe đồ chơi, cốc nước). Hiện mới có ảnh cốc; cần thay bốn vật thể còn lại bằng ảnh chụp nếu muốn tuân thủ đúng playbook.
